
# 🥫 AI-Based Expiry Date Tracker

### Track food freshness. Reduce waste. Stay organized.

An interactive frontend prototype designed to help users manage food products, monitor expiry dates, and keep track of food freshness through a simple dashboard.

The project explores how web technologies and future AI-powered OCR integration can make food-expiry tracking easier and help reduce avoidable food waste.

## 🎯 Problem Statement

People often forget the expiry dates of food products stored at home. This can lead to food wastage, poor inventory management, and accidentally keeping expired products.

The AI-Based Expiry Date Tracker aims to address this problem by providing a centralized interface to manage food items and monitor their expiry status.

## ✨ Features

- 📱 Responsive homepage and user interface
- 📷 Scan/upload interface for food product images
- 🖼️ Image preview before adding products
- 📦 Food inventory management
- ➕ Add new food products
- 🗑️ Delete existing products
- 🟢 Automatic Safe / Expiring Soon / Expired status
- 💾 Local browser storage using localStorage
- 📊 Dashboard counters for monitoring inventory

## 🛠️ Technology Stack

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## ⚙️ How It Works

1. Open the application in a web browser.
2. Add food products to the inventory.
3. Enter the relevant product and expiry information.
4. Monitor the automatically calculated freshness status.
5. Manage your inventory by adding or deleting products.
6. Revisit the application to access locally saved inventory data in the same browser.

## 🖥️ Current Project Status

**Phase 1 — Frontend Prototype**

The current version focuses on the user interface, food inventory management, image preview, expiry-status calculation, and local browser storage.

It does not yet include a connected OCR service, production backend, cloud database, or automated reminder service.

## 🔮 Future Scope

- Integrate OCR to extract expiry dates from product labels.
- Automatically recognize expiry-date information from uploaded images.
- Develop a backend and database for persistent inventory management.
- Implement expiry reminders and browser notifications.
- Explore AI-assisted product recognition.
- Add user authentication and multi-device synchronization.
- Improve the dashboard with food-waste insights and analytics.

## ⚠️ Limitations

- Inventory data is currently stored in the browser's local storage.
- Data is not synchronized across different devices or browsers.
- Expiry dates must currently be entered by the user.
- Image upload and preview do not themselves perform OCR or automatic expiry-date recognition.
- The application is an early-stage prototype and should not be treated as a verified food-safety system.
